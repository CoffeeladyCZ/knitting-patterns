## 🔒 Local HTTPS Setup (Required for Development)

This project requires local HTTPS, which is enabled using certificates generated by **`mkcert`**.

### 1\. Installation and Trust

Install `mkcert` (e.g., via Homebrew on macOS) and run the following command to make your system and browsers trust the local Certificate Authority (CA):

```bash
brew install mkcert # or equivalent for your OS
mkcert -install
```

### 2\. Generate and Name Certificates

In the root directory of the project, generate the certificate files for `localhost`.

```bash
mkcert localhost 127.0.0.1 ::1
```

### 3\. Environment Variables

Ensure your local `.env` file points to these renamed files:

```env
VITE_SSL_CRT_FILE=./server.crt
VITE_SSL_KEY_FILE=./server.key
```

The application should start on a secure connection (e.g., `https://localhost:5173/`) without any browser warnings.
